
# Pet Adoption Prediction

## Опис проєкту

Даний проєкт спрямований на прогнозування швидкості усиновлення тварин на основі текстових описів та зображень. Для цього використовується комбінована модель, що включає **BERT** для обробки тексту та **ResNet50** для аналізу зображень.

## Використані технології

- **Мова програмування**: Python
- **Глибоке навчання**: PyTorch
- **Оптимізація гіперпараметрів**: Optuna
- **Обробка тексту**: Hugging Face Transformers (BERT)
- **Обробка зображень**: torchvision (ResNet50)
- **Робота з даними**: Pandas, Sklearn

## Основні етапи роботи

1. **Підготовка даних**

   - Очищення текстових даних
   - Балансування класів методом апсемплінгу
   - Об'єднання текстових та зображувальних даних

2. **Навчання моделі**

   - Використання комбінації ResNet50 + BERT
   - Оптимізація гіперпараметрів за допомогою Optuna
   - Навчання та валідація на GPU

3. **Оцінка продуктивності**

   - Використання метрики **Quadratic Weighted Kappa (QWK)**
   - Аналіз графіків втрат та продуктивності

4. **Фінальне тренування та збереження результатів**

   - Використання найкращих знайдених параметрів для навчання
   - Генерація прогнозів для тестового набору
   - Збереження результатів у `submission.csv`

## Результати

- Найкраще значення метрики **QWK**: **0.818**
- Підготовлений файл `submission.csv` для завантаження в Kaggle
- Всі `PetID` у тестовому наборі знайдені, жодних втрат немає

## Можливі покращення

- Використання додаткових методів **data augmentation**
- Експерименти з іншими архітектурами для тексту (LSTM, Transformers)
- Використання ансамблевих моделей для покращення продуктивності

## Запуск проєкту

1. Встановіть необхідні бібліотеки:
   ```bash
   pip install torch torchvision transformers pandas scikit-learn optuna tqdm
   ```
2. Запустіть скрипт для навчання моделі:
   ```bash
   python train.py
   ```
3. Згенеруйте прогноз для тестового набору:
   ```bash
   python predict.py
   ```
